# 🚀 From Sputnik to SpaceX

**Visualization of Space Missions Across Decades**

---

## 🌌 Overview

🌐 **Live App**: [from-sputnik-to-spacex.onrender.com](https://from-sputnik-to-spacex.onrender.com)

*From Sputnik to SpaceX* is an interactive web-based visualization project that explores the history and evolution of space missions and astronaut data from **1957 to 2020**. By combining datasets from Kaggle with enriched contextual information from Wikipedia and geolocation services, the application delivers an insightful, interactive experience.

Users can explore missions across time and geography, examining trends in launch destinations, participating countries, commercial companies, and astronauts involved in space exploration.

---

## 💻 Features

* Interactive world map of mission launch sites
* Timeline of global space missions from 1957–2020
* Filtering by name of the mission
* Clean, intuitive visualizations for exploring historical trends
* Accessible via a local web interface

## 🚀 Getting Started

### 📦 Prerequisites

* Python **3.10+**
* `pip` (Python package manager)

### 🔧 Installation

Clone the repository and install dependencies:

```bash
git clone https://github.com/dominik-masar/PA214-Project.git
cd PA214-Project
pip install -r requirements.txt
```

---

## ▶️ Running the App

Simply execute the `main.py` script:

```bash
python main.py
```

Once running, a **local web server** will start. Open the link displayed in the terminal (usually `http://localhost:8050` or similar) to access the app.
